RUNBOOK: Memory Pressure Response
Trigger: HBM memory utilization exceeds 88% of total capacity
Severity Levels:
  - WARNING: 88-91% — identify largest active sessions
  - HIGH: 92-95% — terminate lowest priority sessions, free memory
  - CRITICAL: 96%+ — emergency session termination, potential node restart

Step 1: Query active sessions sorted by memory consumption
Step 2: Identify sessions exceeding context window limits or with memory leaks
Step 3: At WARNING level: enforce context truncation on long-running sessions
Step 4: At HIGH level: terminate bottom 20% of sessions by priority score
Step 5: Verify memory releases within 60 seconds of session termination
Step 6: If memory does not release, suspect kernel leak — escalate to driver restart
Step 7: Driver restart requires full node failover first — never restart under active load
Step 8: Post-incident: review model serving configuration for memory ceiling enforcement
Recovery: Resume normal operations when memory drops below 80% and holds for 5 minutes
